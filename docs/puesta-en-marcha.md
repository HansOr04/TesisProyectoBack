# Puesta en marcha con la fundación

## Carga de los datos reales (HU-74)

La fundación llena estas dos tablas; después se registran en la plataforma. No se
envían contraseñas por correo ni por chat: cada persona recibe la suya en
persona.

**Organizaciones**

| Nombre | Tipo (asociación nivel 1, nivel 2 o empresa) | Asociación a la que pertenece | País y región | N.º de socios | Producto principal | Correo y teléfono | Evaluador a cargo | KPI que no aplican |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |

**Usuarios**

| Nombre | Correo | Rol (administrador, evaluador o visualizador) | Organizaciones que evalúa o consulta |
|---|---|---|---|
| | | | |

Orden de carga: respaldo, usuarios, asociaciones de nivel 2, resto de
organizaciones, evaluadores asignados y KPI aplicables. Al final se compara con
las tablas y la fundación firma que coincide (CA-74.1).

## Capacitación de los facilitadores (HU-77)

Sesión de 2 horas, en un **proyecto de práctica** aparte para no mezclar datos
reales. Material: el manual de usuario.

| Tiempo | Tema | Qué hace cada facilitador |
|---|---|---|
| 10 min | Qué es y los roles | Inicia sesión con su cuenta |
| 20 min | Registrar (manual, 2) | Registra una organización de práctica |
| 30 min | Calificar (3) | Califica una dimensión, consulta la rúbrica y prueba sin conexión |
| 15 min | Completar (4) | Revisa el resumen |
| 20 min | Planificar (5) | Crea dos medidas y registra un avance |
| 10 min | Exportar (6) | Genera el reporte y lo revisa |
| 15 min | Dudas | |

**Evaluación de práctica (CA-77.1).** Sin ayuda, cada facilitador registra una
organización, completa una evaluación de Capacidades (30 KPI), crea una medida y
exporta el reporte.

| Facilitador | Registró | Completó | Creó medida | Exportó | ¿Necesitó ayuda? |
|---|---|---|---|---|---|
| | | | | | |

La historia se cierra cuando todos tienen las cuatro y la última columna en «No».
